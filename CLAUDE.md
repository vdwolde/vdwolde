# Profile — agent instructions

This repository is the GitHub profile README of `vdwolde`: GitHub shows the root `README.md` on the profile page because the
repository is named like the account (`vdwolde/vdwolde`). It is **public**, so everything in it is public.

## Hard rules

1. Nothing private goes in: no private repository names or links, no work (Sopra Steria, Vattenfall) content, no client names,
   no personal data. The profile's bio, company and location are set on github.com and are not changed from here.
2. Never invent content. The README holds the banner, the guide's tagline and the link to https://vdwolde.com/. Anything
   else is added only when the owner asks for it.
3. Never commit, push or open a PR unless the owner asks in that turn.

## Brand

Brand Guide v1.0 (`Branding/` in the Development Base). `assets/` holds the guide's profile banners (dark and light) copied from
`Branding/github/profile/`; never edit them by hand. The avatar (`Branding/github/profile/avatar-460.png`) is uploaded on
github.com, there is no API for it.

## Quality gate

Docs-only: no build, no tests. Check that the banner paths in `README.md` resolve and that nothing private is named.
